# 🤖 Dual Strategy Trading Bot

## 📊 Описание

Бот запускает **ДВЕ параллельные стратегии** с одинаковыми параметрами, но разной логикой повторных покупок:

### **Strategy A: No Rebuy (Консервативная)**
- ✅ Покупает токен **только один раз**
- ❌ После продажи с прибылью **НЕ покупает** этот токен снова
- 🎯 Фокус на **новых возможностях**
- 💡 Логика: "Взял прибыль и ушел"

### **Strategy B: Rebuy (Агрессивная)**
- ✅ Покупает токен **первый раз**
- ✅ После продажи с прибылью **МОЖЕТ купить снова**
- ❌ После stop-loss **НЕ покупает** повторно
- 🎯 Фокус на **повторных волнах роста**
- 💡 Логика: "Если сработало раз, может сработать снова"

## 🎯 Параметры (одинаковые для обеих)

- **Начальный баланс:** $100 каждая
- **Размер позиции:** $0.50
- **Цель прибыли:** +10%
- **Stop-loss:** -50%
- **Максимум позиций:** 20

## 📈 Статистика

Бот выводит сравнительную статистику каждые **60 итераций** (~2 минуты):

```
📊 COMPARISON #60

Strategy A (No Rebuy):
💰 Balance: $100.50
📈 P&L: $+0.50 (+0.5%)
📊 Positions: 2
🛒 5B / 3S

Strategy B (Rebuy):
💰 Balance: $101.20
📈 P&L: $+1.20 (+1.2%)
📊 Positions: 3
🛒 8B / 5S

🏆 B | ⏱ 0.5h
```

- **Telegram:** Стартовое сообщение, сравнения каждые 60 итераций, финальная статистика

## 🔍 Что отслеживается

### Для каждой стратегии:
- 💰 **Balance** - текущий баланс
- 📈 **P&L** - чистая прибыль/убыток
- 📊 **Positions** - количество открытых позиций
- 🛒 **Buys/Sells** - количество сделок
- 💚 **Profit** - общая прибыль
- 💔 **Loss** - общие убытки

## 🏆 Определение победителя

Стратегия с **большим Net P&L** (прибыль - убытки) считается победителем.

## 💡 Ожидаемые результаты

### Strategy A (No Rebuy) может выиграть если:
- Много **новых токенов** с хорошим ростом
- Повторные покупки часто приводят к **убыткам**
- Рынок **трендовый** (каждый токен растет один раз)

### Strategy B (Rebuy) может выиграть если:
- Токены показывают **несколько волн роста**
- Мало новых токенов, но старые **снова растут**
- Рынок **волатильный** (токены качаются вверх-вниз)

## 📝 Примеры логов

### Покупка:
```
🟢 [A] BUY CjFryrsV... | $0.5000
🟢 [B] BUY CjFryrsV... | $0.5000
```

### Продажа с прибылью:
```
🟢 [A] SELL CjFryrsV... | +12.5% | +$0.0625
🟢 [B] SELL CjFryrsV... | +12.5% | +$0.0625
```

### Повторная покупка (только B):
```
🟢 [B] BUY CjFryrsV... | $0.5000  ← Второй раз!
```

### Токен без ликвидности:
```
💀 [A] NO LIQUIDITY wJtJ1rM1... | -$0.5000
💀 [B] NO LIQUIDITY wJtJ1rM1... | -$0.5000
```
